## Every mutation hook, and what it invalidates

| Hook                                                                                                                              | File                               | Invalidates                                                                                            |
| --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `useCreateMapping`, `useUpdateMapping`, `useDeleteMapping`, `useBulkDeleteMappings`, `useImportMappings`, `useSetMappingDisabled` | `mappings/api/use-mappings.ts`     | `mappingsKey(server)` (+ single-mapping key for update)                                                |
| `useSaveFile`, `useDeleteFile`                                                                                                    | `files/api/use-files.ts`           | file list key, single-file key                                                                         |
| `useResetAllScenarios`, `useResetScenario`, `useSetScenarioState`                                                                 | `scenarios/api/use-scenarios.ts`   | scenarios key                                                                                          |
| `useRemoveServeEvent`, `useClearJournal`                                                                                          | `requests/api/use-requests.ts`     | journal key                                                                                            |
| `useStartRecording`, `useStopRecording`, `useSnapshotRecording`                                                                   | `recordings/api/use-recordings.ts` | recording-status key; stop/snapshot also invalidate `mappingsKey` (imported from the mappings feature) |
| `useUpdateGlobalSettings`                                                                                                         | `settings/api/use-settings.ts`     | settings key                                                                                           |
| `usePersistMappings`                                                                                                              | `settings/api/use-settings.ts`     | none (no cached data changes)                                                                          |
| `useResetMappingsToDefault`                                                                                                       | `settings/api/use-settings.ts`     | `mappingsKey` (imported from the mappings feature)                                                     |
| `useResetServerState`                                                                                                             | `settings/api/use-settings.ts`     | every query key containing the server's ID (predicate-based)                                           |

This table is the fastest way to answer "if I change X, what needs to
refetch?" without re-deriving it from each hook file.
